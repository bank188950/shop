โค้ดวิกิสำหรับ repository ในเครื่องนี้ ให้ความสำคัญกับ quickstart ที่กระชับ, ภาพรวมสถาปัตยกรรม, แผนผังซอร์สโค้ด, workflow สำคัญ, แนวคิดของ domain, บันทึกการดำเนินการ/runbook, แนวทางการทดสอบ และจุดเชื่อมต่อระบบ ตรวจสอบประวัติ git เพื่อทำความเข้าใจเหตุผลเบื้องหลังการเปลี่ยนแปลงโค้ดและพัฒนาการของ repository ให้เนื้อหาของแต่ละหน้ายึดตามโครงสร้างของ repository และการเปลี่ยนแปลงโค้ดล่าสุด เน้นการนำทางเชิงปฏิบัติสำหรับวิศวกรมากกว่าบทสรุปแบบทั่วไป

เขียนเนื้อหาทุกหน้าเป็นภาษาไทย โดยคงภาษาอังกฤษไว้เฉพาะสิ่งที่จำเป็นต้องทับศัพท์เท่านั้น เช่น โค้ด/คำสั่ง, ชื่อไฟล์และ path, ชื่อ table/คอลัมน์/ฟิลด์, ค่าสถานะในโค้ด, ชื่อเทคโนโลยี (React, Vite, PHP, MySQL, API ฯลฯ), ฟิลด์ `tags` และ mermaid diagram หากแปลข้อความหัวข้อ (heading) เป็นภาษาไทย ต้องอัปเดตลิงก์ที่อ้างอิง anchor ของหัวข้อนั้นให้ตรงกันด้วย
