# ไฟล์

- [แนวคิดด้านการค้าและช่องว่างของการเก็บข้อมูลถาวร](domain-model.md) - เอนทิตีใน MySQL, คำศัพท์คำสั่งซื้อฝั่ง frontend และความไม่สอดคล้องของ contract ที่ขัดขวาง commerce workflow ที่รองรับด้วยเซิร์ฟเวอร์
- [การดำเนินการ, การเชื่อมต่อระบบ และการทดสอบ](operations.md) - การตั้งค่าเครื่อง local, การ deploy บน Apache, การกำหนดค่า API, ขั้นตอนการตรวจสอบ และข้อจำกัดด้านความปลอดภัยและการเชื่อมต่อระบบในปัจจุบัน
- [โค้ดวิกิ ลูกชิ้นทอดล้อเลื่อน](quickstart.md) - จุดเริ่มต้นสำหรับ React storefront, โครงสร้าง PHP API, MySQL schema และต้นแบบการทำงานฝั่งผู้ดูแลที่เก็บสถานะในเบราว์เซอร์
- [แผนผังซอร์สโค้ดสำหรับวิศวกร](source-map.md) - แผนที่นำทางเชิงปฏิบัติสำหรับ entrypoint ของแอปพลิเคชัน, ฟีเจอร์เฉพาะบทบาท, โครงสร้างการเก็บข้อมูล, งานออกแบบ และระบบอัตโนมัติ
